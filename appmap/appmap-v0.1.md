# App Map v0.1 — Búsqueda de mascotas perdidas

## Objetivo

Organizar las principales partes de la aplicación y mostrar dónde puede encontrar el usuario la información o acción que necesita.

## Estructura de la aplicación

- Inicio
  - Buscar mascota
  - Mascotas cerca
  - Reportar mascota perdida
  - Reportar mascota encontrada
  - Reportar avistamiento

- Buscar
  - Mascotas perdidas
  - Mascotas encontradas
  - Avistamientos
  - Filtros
    - Ubicación
    - Fecha
    - Especie
    - Características
  - Detalle del reporte

- Reportar
  - Mascota perdida
    - Fotografía
    - Nombre
    - Características
    - Última ubicación
    - Fecha de pérdida
    - Datos de contacto

  - Mascota encontrada
    - Fotografía
    - Características
    - Ubicación
    - Fecha
    - Datos de contacto

  - Avistamiento
    - Fotografía
    - Ubicación
    - Fecha y hora
    - Descripción

- Mis reportes
  - Mascotas perdidas
  - Mascotas encontradas
  - Avistamientos
  - Detalle del reporte
  - Actualizar reporte
  - Marcar como resuelto

- Coincidencias
  - Posibles coincidencias
  - Información de la mascota
  - Fotografías
  - Ubicación
  - Fecha del reporte
  - Avistamiento relacionado
  - Contactar usuario

- Perfil
  - Información del usuario
  - Mis datos de contacto
  - Configuración
