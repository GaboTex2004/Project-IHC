# Observaciones del Usuario

A partir del análisis realizado para la aplicación móvil de búsqueda de mascotas perdidas, se identificaron las siguientes observaciones:

1. **Importancia del tiempo:** Los usuarios necesitan encontrar información relevante rápidamente, ya que el tiempo es un factor importante cuando una mascota se encuentra perdida.

2. **Información visual y ubicación:** Las fotografías y la ubicación son elementos fundamentales para que los usuarios puedan identificar una mascota y relacionarla con posibles reportes o avistamientos.

3. **Participación de la comunidad:** Los avistamientos y pistas proporcionados por otros usuarios pueden ser determinantes para localizar una mascota perdida, por lo que la aplicación debe facilitar el registro de esta información.

4. **Comunicación segura:** Los usuarios necesitan una forma sencilla y segura de comunicarse para intercambiar información sobre la mascota sin exponer innecesariamente sus datos personales.
